# 华尔街纯技术流（道氏 + 波浪 + 裸K）实战深度手册

本文档为交易助手提供深度的理论依据与几何形态学操作细则，严禁引用任何滞后指标，所有规则严格建构于价格、结构与时间之上。

---

## 一、 道氏理论：趋势定性与基准指数相互验证

### 1. 道氏客观高低点序列 (Dow Swing Sequence)
* **绝对上升趋势 (Uptrend)**：连续出现更高的波峰与更高的波谷（`HH` + `HL`），每一次回调只要不破前低，多头结构保持完整。
* **绝对下降趋势 (Downtrend)**：连续出现更低的波峰与更低的波谷（`LH` + `LL`），每一次反弹只要不破前高，空头结构保持完整。
* **震荡整理 (Trading Range)**：高低点序列混乱（如 `HH` 后出现 `LL`，或 `LH` 后出现 `HL`），此时视为无主趋势，操作转为箱体边界博弈。

### 2. 基准指数协同性 (Market Breadth Confirmation)
* 道氏理论核心命题：**“指数必须相互验证”**。
* 同步对比标普500 (`SPY`)、纳斯达克100 (`QQQ`) 与道琼斯工业指数 (`DIA`)：
  * **健康多头共振**：三大指数同步创出波段新高（HH）；
  * **道氏未确认/背离 (Dow Non-Confirmation)**：若纳指创新高（科技股狂热），但标普或道指未能同步创新高（权重与传统工业股滞涨），往往预示行情进入派发期末期，必须警惕假突破与断崖回踩。

## 二、 艾略特波浪理论：三大铁律与斐波那契坐标尺

### 1. 推动浪三大不可违背铁律（一票否决）
在划分任何标准驱动浪（1-2-3-4-5）时，必须显式满足以下三条数学铁律：
1. **铁律一：浪 2 的回撤绝不能跌破浪 1 的起点。** 回撤一旦达到 100%，该数浪体系立即作废。
2. **铁律二：在 1、3、5 三个推动浪中，浪 3 绝对不能是最短的一浪。** 浪 3 通常是成交量最大、斜率最陡、最具爆发力的主升浪。
3. **铁律三：浪 4 的回撤低点绝不能进入浪 1 的价格领域（顶底不重叠）。** 浪 4 底严禁跌破浪 1 顶（罕见的倾斜三角形/楔形除外）。

### 2. 波浪交替原则 (Guideline of Alternation)
* **形态与深度交替**：
  * 若浪 2 为急跌、深幅度调整（通常为单锯齿形 A-B-C，回撤达浪1的 0.500 或 0.618）；
  * 则浪 4 倾向于表现为耗时较长、浅幅度的复杂横向震荡（如平台形、三角形或旗形，回撤通常仅为 0.236~0.382）。

### 3. 斐波那契坐标集群 (Fibonacci Clusters)
* **回撤比率 (Retracement)**：`0.382`（强势浅回撤）、`0.500`（中轴多空平衡位）、`0.618`（黄金分割极致防线）、`0.786`（深度试探）。
* **顺势扩展比率 (Extension)**：`1.272`（第一波段测量目标）、`1.618`（主升浪浪3/浪5标准目标）、`2.618`（超强爆发扩展位）。

## 三、 平行趋势通道（Trend Channels）几何画法

1. **上升通道绘制三部曲**：
   * **确定底轨（支撑线）**：至少找到两个扎实的波谷低点（L1, L2），画出斜向上的主趋势线；
   * **推演顶轨（阻力线）**：将底轨平行复制，移至 L1 与 L2 之间的最高波峰（H1）；
   * **验证通道**：若后续波峰与波谷均在此平行轨道内受阻反弹，证明通道高度有效。
2. **通道内交易战术**：
   * **下轨触碰**：出现长下影线或小实体企稳，是高盈亏比的顺势做多买点；
   * **上轨触碰**：严禁追多，提示“短线要等一等”或“分批兑现减仓”。

## 四、 水平顶底转换（S/R Flip）与矩形箱体

* **顶底转换机制**：
  * 市场中大量空头止损盘与突破追多盘集中在前期显著高点。一旦该高点被放量击穿，原阻力位转化为坚不可摧的支撑垫；
  * **最佳买点**：并非突破的一瞬间，而是价格温和缩量回踩测试该水平平台并形成止跌K线时（Retest）。
* **矩形箱体法则**：
  * 当趋势线被跌破后，若未出现单边崩塌，通常演化为宽幅震荡箱体；
  * 锁定箱体最高价（阻力）与最低价（支撑），执行“箱底低吸、箱顶高抛”，直至某一侧发生放量有效突破。

## 五、 跳空缺口（Gap）的实战分类与力场效应

美股因盘后财报与全球宏观事件，经常产生跳空缺口：
1. **突破缺口 (Breakaway Gap)**：发生在长期盘整箱体或关键颈线的突破点，伴随巨量，通常不会在短期内回补，代表新趋势确立；
2. **持续缺口 (Runaway / Measuring Gap)**：在主升浪中段出现，往往位于整段行情的中间位置，具备目标测量意义；
3. **竭尽缺口 (Exhaustion Gap)**：在加速赶顶或恐慌探底时出现，伴随成交量极度放大，随后迅速被反向K线回补，是强烈的转折反转信号；
4. **未回补缺口的作用**：
   * 任何留在下方的未回补看涨缺口（Bullish Gap），在价格回调时均构成天然支撑位；
   * 任何留在上方的未回补看跌缺口（Bearish Gap），在价格反弹时均构成严重阻力带。

## 六、 微观价格行为（Price Action）与 2B 流动性猎杀

1. **Pin Bar（长影线拒绝）**：
   * 下影线 >= 实体2倍且占总振幅 >= 60%：代表盘中空头试探后被强力多头扫回，多头买点；
   * 上影线 >= 实体2倍且占总振幅 >= 60%：代表多头冲高被上方筹码无情砸回，空头卖点。
2. **2B 假突破 / 流动性猎杀 (Liquidity Sweep)**：
   * **做空形态**：价格快速刺破前期显著高点（Sweep High），打掉空头止损单并诱惑散户追高，但随后立刻跌回收盘于前高下方。这是主力资金利用散户流动性离场的经典 2B 顶，是极佳的右侧空单入场点；
   * **做多形态**：价格快速跌破前期显著低点（Sweep Low），扫掉多头止损盘，但随后迅速长针收回于前低上方，确认诱空完毕，启动暴力反弹。

## 七、 板块联动与领头羊对标（Sector Leadership）

* 任何个股走势均非孤立存在。
* 在分析个股前，必须锚定其细分板块的龙头标的：
  * **存储板块**：闪迪 (SNDK) / 美光 (MU) / 西部数据 (WDC)
  * **芯片制造/算力**：台积电 (TSM) / 英伟达 (NVDA) / 博通 (AVGO) / 阿斯麦 (ASML)
  * **软件/云计算**：微软 (MSFT) / 赛富时 (CRM) / 甲骨文 (ORCL)
* 若当前分析的标的处于二线跟随地位，而板块龙头已经突破新高或率先完成回踩企稳，该个股往往具备高胜率的补涨或结构修复机会。
