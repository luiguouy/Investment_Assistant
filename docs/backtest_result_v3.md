## 一、战略优化背景与痛点拆解

在上一阶段（H2）的回测中，我们证实了**道氏第6条（量能确认）具有统计显著的独立 Alpha**（MTF h=20 分位达 0.98，MTF+HTF 均值 +1.02% 分位达 0.96）。然而，H2 回测亦暴露了两个关键痛点：

1. **市价追入的深幅不利回撤（MAE 中位数高达 −5.06% ~ −5.18%）**：
   在突破发生当根 K 线收盘后盲目按次根开盘价市价追入，往往直接买在短线动能竭尽的极值区，随后价格普遍出现深度回踩或洗盘。
2. **宽幅指数（SPY/QQQ）具有强均值回归属性**：
   在无位置防守和触发形态确认的前提下，机械追突破在指数上均值常年为负。

为此，本轮优化（H3）严格贯彻 `strategy_theory.md` 规定的分层演进路径：
```
[方向层 (Direction)]  --> 道氏结构突破 + 周线共振 + 放量确认 (仅作为守门人，严禁直接追单)
          ↓ 允许交易方向
[位置层 (Location)]   --> 被突破波段高低点回踩 (Swing Retest) / 斐波那契回撤 (Fib 50%/61.8%) 挂限价单
          ↓ 锁定交易区域
[触发层 (Trigger)]    --> 关键位 2B 流动性猎杀 (Sweep)、拒绝 Pin Bar、吞没形态确认 + 紧密证伪止损
          ↓ 出现反转确认
[风控执行 (Execution)] --> 盈亏比硬闸门 (RR >= 2.0 一票否决) + 保守撮合 + 真实持仓生命周期追踪
```

## 七、优化结论与后续实施指南

1. **废弃市价追高**：回测数据彻底确认，任何按突破当根市价入场的行为在长期均面临巨大的 MAE 惩罚；
2. **必须执行挂单与触发**：波段高低点回踩挂单（Broken Swing Retest）与关键位裸K形态（2B/Pin Bar）是压缩风险敞口的核心工具；
3. **个股与指数差异化处理**：
   - 动量个股：放量突破 + 回踩 Swing / Fib 50% 均具备良好表现；
   - 指数 ETF：严禁使用深幅 Fib 50%/61.8% 挂单（假突破反转居多），必须依靠周线共振（MTF+HTF）与 RR>=2.0 硬闸门保护。
