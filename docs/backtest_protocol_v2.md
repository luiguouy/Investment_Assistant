- **理论依据**：`strategy_theory.md`（道氏第5条与第6条、反转与突破定义）

## 一、为什么需要 H2 协议

在第一轮回测（`backtest_result_v1.md`）中，原假设 H1（使用 `dow_bias()` 最近 4 个拐点的 HH/HL 标签计数来判定结构偏向）未获统计支持（MTF h=20 均值 −0.13%，分位 0.20，且 h=40 显著劣于随机）。

在 `backtest_result_v1.md` 第六节归因分析中，核心根因被定位为**操作化失真与严重确认滞后**：
1. 标签计数法要求至少 4 个拐点（每个波峰/波谷需要 `order=5` 根 K 线右侧确认），等凑够数时，趋势行情往往已经运行了 20–40 根 K 线，接近尾声或进入回调；
2. 真实的道氏理论（Dow 1902, Rhea 1932）反转与突破信号是**收盘价对前一个结构关键位的有效穿越（Displacement / Close Crossing）**，而不是拐点标签的累加。

因此，按照严格的量化研究纪律，我们开启 **H2 预注册协议**：将方向层的判定从「拐点标签计数」重构为「收盘价穿越最新已确认结构位 + 区间内趋势延续」。

---

## 二、主检验（唯一，不可事后更换）

> **H2**：在日线上出现「收盘价对最新已确认波段高点/低点形成结构突破（且处于趋势转移点）」之后，未来 **20 根** K 线的方向性收益，显著高于同期同方向的随机入场。

| 项 | 设定 |
|:---|:---|
| 组别 | `MTF` 组（日线结构突破偏向，不加周线过滤） |
| 持有期 | **h = 20 根**（唯一主检验） |
| 入场 | 第 t 根收盘判定状态转移 → **第 t+1 根开盘**入场 |
| 判定函数 | `pe.dow_bias(d_sw, df=df_sub)`：收盘突破最新已确认高点设为 +1，跌破低点设为 -1，区间内沿用最近一次突破方向（道氏第5条：趋势持续直到反转） |
| 指标 | 平均方向性收益（空头收益取负） |
| 对照 | 从同一序列所有可用决策根中，抽取**同数量、同多空比例**的随机入场，重复 400 次 |
| 判定标准 | 观测值在对照分布中的分位 **≥ 0.95 → 支持 H2**；0.05~0.95 → **无结论**；≤ 0.05 → **显著劣于随机** |
| 样本 | `tickers.txt` 30 只美股（2019-03 → 2026-10，每只 1920 根） |

## 三、次要检验与探索性分组（预先定义）

为防止多重比较导致的虚假显著，以下检验均属于探索性，不作为 H2 成立的判定标准：

1. **持有期敏感性**：h = 5 / 10 / 40 根 K 线。
2. **`MTF+HTF` 组**：日线与周线双重结构突破确认（检验道氏三级联立的过滤价值）。
3. **量能确认过滤组（`volume-filter`）**：
   - 理论依据：道氏第 6 条「成交量应验证趋势」与 Wyckoff 努力/结果原理。
   - 判定：突破当根成交量需大于过去 20 根均量的 1.2 倍，无量突破视为假突破不入场。
4. **多空不对称性分解**：单独观察做多（突破前高）与做空（跌破前低）在牛市样本中的表现。
5. **四只指数 ETF 跨样本验证**：SPY / QQQ / DIA / IWM（2008–2026 跨越牛熊周期）。

## 四、引擎验证（已通过）

执行 `python backtest.py --verify`，必须全绿方可启动真实回测：

| 检验项 | 内容 | 验证结果 |
|:---|:---|:---|
| **T1 未来函数自检** | 在 T=300, 450, 600 三个截断点用子序列重算，历史决策集与全序列完全一致 | ✅ 通过（15/15, 23/23, 28/28 全等） |
| **T2 入场时点** | 第 t 根决策，第 t+1 根开盘价成交，收益误差 < 1e-12 | ✅ 通过 |
| **T3 周线越界** | 严格限制周线聚合标签日期 <= 当日，不使用未完结周 | ✅ 越界 0 次 |
| **T4 MAE/MFE 口径** | 满足 `MAE <= 0 <= MFE` 且 `MAE <= 收益 <= MFE` | ✅ 通过 |
| **T1-H1 兼容性** | 历史 H1 标签计数模式同样通过未来函数自检 | ✅ 通过（5/5, 7/7 全等） |
